# 在先技术与授权风险矩阵

版本日期：2026-09-07

性质：公开网页和论文的初步技术检索，不是专利代理机构出具的查新报告或 FTO 意见。

## 1. 候选独立权利要求要素

| 编号 | 要素 |
|---|---|
| A | 整夜睡眠记录划分为多个时间片段并输出多阶段后验概率 |
| B | 模型拟合受试者、校准受试者和待处理受试者按受试者标识隔离 |
| C | 在独立校准受试者上以多分类 NLL 拟合温度参数 |
| D | 由校准后验概率计算归一化 entropy 或 posterior margin |
| E | 按整夜、预测阶段和阶段转移边界中的至少两类范围聚合 |
| F | 与睡眠宏结构、动态、AHI、觉醒和人口学变量融合 |
| G | 输出抑郁症状量表阈值对应的辅助风险参数 |
| H | 对已校准后验执行概率幂变换，生成多个温度敏感性后验序列 |
| I | 将各序列输入参数不变的同一风险模型，形成受试者级风险区间 |
| J | 风险区间跨过判别阈值时停止确定性分类并输出待复核标志 |

修订后的候选区分点是 B-C-H-D-E-I-J 的有序数据流，重点落在“无需重新执行分期模型
的温度视图生成、校准敏感性跨层传播、风险区间和阈值翻转判别”。该组合是否具备
创造性，仍取决于正式检索能否找到组合启示。

## 4. 新颖性判断

初步结论：

- A、D、F、G 分别已有明确公开。
- C 作为机器学习概率校准手段也属于已知方法。
- 当前尚未发现单一对照文件明确公开 B-C-H-D-E-I-J 的全部有序组合。
- 现有睡眠不确定性工作主要在分期层拒绝时间片段；本方案把校准温度变化传播到下游
  受试者级风险区间，并据此决定是否输出确定性风险倾向。
- 因此候选权利要求可能存在形式上的新颖性空间，但不能据此推导具备创造性。

正式检索应优先使用以下组合式查询：

- sleep staging + posterior probability + temperature calibration + entropy；
- subject-disjoint calibration + polysomnography + risk prediction；
- calibrated uncertainty + sleep stage + depression；
- calibrated posterior + temperature sensitivity + downstream risk interval；
- sleep staging + calibration perturbation + threshold crossing + abstention；
- 睡眠分期 + 后验概率 + 温度校准 + 熵；
- 受试者隔离 + 概率校准 + 生理信号 + 风险评估。
- 睡眠分期 + 温度敏感性传播 + 风险区间 + 待复核。

## 5. 创造性风险

原权利要求的主要审查风险是：审查员可能以 CN117530689A 或 Pan et al. 作为最接近
现有技术，再结合 SleepTransformer/Kang 的 entropy 与 Guo et al. 的温度校准，认为
本申请只是把已知概率校准和不确定性指标用于已知的睡眠抑郁分析流程。

修订后新增的创造性支撑包括：

- 从已校准后验直接生成多个温度视图，不重复执行分期模型；
- 各视图使用同一风险模型，风险变化可归因于上游校准敏感性；
- 风险区间跨阈值时触发待复核标志，形成从分期概率到下游输出控制的闭环；
- 正负10%实验在嵌套五折和风险模型层留一中心中均识别出误判率更高的跨阈值组。

以下事实仍削弱创造性论证：

- 增量只在 ExtraTrees 和 HAMD 二分类中得到支持；
- BDI-I、连续终点和 SGD backbone 没有稳定复现；
- 条件残差和周期相位为负结果；
- 当前未完成真正独立数据集上的 E4 外部验证；
- 当前实施例使用预提取 YASA 特征，而非原始 EEG backbone。
- 温度倍率范围是工程敏感性容差，不是统计置信区间；
- 选择性预测、风险区间和拒绝机制分别属于已知方法，创造性仍依赖具体数据流组合。

综合评级：**相较原方案有所改善，但授权风险仍为中高。正式提交前必须完成权利要求
全文查新，并由专利代理人评估组合启示和专利客体风险。**

## 6. 专利客体风险

中国专利法通常不授予疾病诊断和治疗方法专利。候选文本应保持为生理数据处理和
辅助风险参数生成，不把输出直接定义为疾病诊断结论。

需要代理人重点审查：

- 权利要求是否包含获得疾病诊断结果的全部必要步骤；
- “HAMD 阈值辅助风险参数”是否仍会被认定为直接诊断结果；
- 是否应以数据处理系统、设备和存储介质作为主要独立权利要求；
- 是否需要删除“待处理受试者”并改写为对已获得数据的离线处理。

## 7. 充分公开和支持风险

| 风险 | 当前状态 | 处理 |
|---|---|---|
| raw EEG backbone 未验证 | 443 人数据已保留，但未用于当前结果 | 不在实施例中声称已验证 |
| 跨 backbone 稳定性不足 | SGD 未复现 | 不主张模型无关效果 |
| 连续严重度预测不足 | CI 跨零 | 不写入有益效果 |
| 外部数据集验证不足 | Bovy 无 posterior | 不声称独立队列外部验证 E4 |
| 校准算法范围过宽 | 仅温度缩放得到验证 | 独立权利要求优先限定温度缩放 |
| 风险模型范围过宽 | 当前验证为类别加权逻辑回归 | 实施例和从属项明确该模型 |

## 8. 推荐申请策略

1. 独立权利要求聚焦 B-C-H-D-E-I-J，不再把一般性的“分期加抑郁分类”当作核心。
2. 明确幂变换公式、同一风险模型参数不变、风险上下界和跨阈值复核条件。
3. 将正负10%结果写入实施例，同时注明它是工程敏感性容差。
4. 暂不主张“条件残差 + 周期相位”，也不声称拒绝机制提高全体样本准确率。
5. 系统、设备和存储介质权利要求与方法权利要求同步准备。
6. 在提交前补做严格端到端嵌套验证和独立数据集验证；若不能复现，收窄保护范围。
7. 由代理人检索 CNIPA、WIPO、EPO、USPTO 的标题、摘要、说明书和权利要求全文，并
   检查同族专利和引用网络。
