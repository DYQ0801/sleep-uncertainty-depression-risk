## 查看旧稿与恢复文档

历史稿中的路径按写作时的项目根目录理解。移动后不逐篇改写旧稿中的文字路径，以便保留原始证据；原路径到当前位置的映射以清单为准。

需要核验整理完整性时，在项目根目录运行：

```bash
python3 archive/2026-10-01/restore_documents.py --check
```

该命令核验 99 个原始文档／资源文件的保留副本，以及整理开始时记录的 27 个代码、测试、配置与聚合指标文件。若以后主动修改实验代码或指标，相应检查会提示“自整理后已改变”，不代表整理时丢失文件。

需要恢复清理前的文档目录时，将原文件复制到一个尚不存在的目录：

```bash
python3 archive/2026-10-01/restore_documents.py \
  --destination restored_documents_20261001
```

恢复脚本不会覆盖当前目录；它重建原文档布局并逐文件核验哈希。去掉的 13 个重复文件从 `materials/思路/` 复制恢复。数据集和实验环境没有移动，不在这份文档恢复范围内。
